# Proyecto Final Automation Testing - Erika Silverio

## Descripción
Framework de automatización integral desarrollado en Python.
Combina pruebas de interfaz web sobre SauceDemo utilizando Selenium WebDriver y pruebas de servicios backend (API) utilizando Requests, aplicando los patrones (POM) y (DDT).

## Tecnologías utilizadas
- Python 3.13
- Pytest y pytest-html
- Selenium WebDriver
- Requests
- Git y GitHub
